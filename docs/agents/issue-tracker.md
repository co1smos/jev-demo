# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues at https://github.com/co1smos/jev-demo/issues.

Use the `gh` CLI from the repository root. Publish one issue per approved ticket, apply `ready-for-agent`, and express blocking edges with GitHub's native issue dependencies when available plus a human-readable `Blocked by` section.

Pull requests are not a request/triage surface.
